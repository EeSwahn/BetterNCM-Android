# BNA 快速定位手册（源码文件 + 功能索引）

> 面向后续 Agent：修改或排查某功能时，先在此定位文件 / 函数，再打开对应源码，
> 可大幅减少翻阅上下文。文件路径均相对项目根目录。
> 约定：`★` = 高频改动点 / 核心逻辑；`主文件` 段落用于大方向定位，`功能→位置` 索引用于精确到函数/键名。

二进制文件（jks/jar/webp/png 等）不属于源码，不在此展开。

---

## 一、整体分层一览（读代码顺序建议）

1. 入口：`MainActivity.kt` → `MainScreen.kt`
2. 页面：`Splash` / `Login` / `Search` / `PlayerBar` / `LyricsScreen`
3. 状态：`viewmodel/`
4. 数据：`data/repository` → `data/network` / `data/model`
5. 播放：`player/` + `service/MusicService.kt`
6. 歌词 UI 子模块：`ui/screen/lyrics/`（功能最集中、改动最多）

---

## 二、根目录与构建

- `build.gradle.kts`：项目级构建入口（插件声明，不直接应用）。
- `settings.gradle.kts`：插件/依赖仓库、根工程名，include `:app`。
- `gradle.properties`：JVM / AndroidX / R class 策略等参数。
- `gradle/libs.versions.toml`：依赖版本目录（`libs.*` 别名）。
- `gradle/wrapper/gradle-wrapper.properties`：Wrapper 分发配置。
- `gradlew` / `gradlew.bat`：Wrapper 启动脚本。
- `auto_build_install.bat` / `auto_build_install.ps1`：一键构建安装脚本。
- `源码文件说明.md`：本文件旧版（已更名为本文件 `快速定位.md`）。

## 三、App 模块 / 清单 / 资源

- `app/build.gradle.kts`：应用模块构建配置（SDK、签名、Compose、依赖）。
- `app/proguard-rules.pro`：混淆规则。
- `app/src/main/AndroidManifest.xml`：权限、`MainActivity`、`MusicService` 声明。
- `app/src/main/res/values/strings.xml`：字符串（应用名等）。
- `app/src/main/res/values/themes.xml`：系统主题 `Theme.BNA`。
- `app/src/main/res/xml/backup_rules.xml`、`data_extraction_rules.xml`：备份/迁移规则模板。
- `app/src/main/res/drawable-nodpi/bna_logo.png`：Logo / 应用图标。
- `app/src/main/res/drawable/salt_ic_*.xml`：播放/暂停/上下首等矢量图标。

# 功能 → 位置索引（精确到函数 / 键名）

> 用法：搜“我要改 X”→ 看下面该行 → 打开对应文件定位函数/键。

## A. 歌词页基础

- 歌词屏切换平板/手机：`ui/screen/LyricsScreen.kt` → `isTablet`
- 滚动追焦列表：`LyricsComponents.kt` → `LyricsPanel`
- 单行渲染 / 放大字号：`LyricsComponents.kt` → `LyricLineItem`
- 逐字歌词流(换行)：`LyricsComponents.kt` → `WordByWordLyricsFlow`
- 歌名扫描发光（5.5s 左→右）：`LyricsComponents.kt` → `ScanningGlowText`（被 `TabletLyricsLayout`/`PhoneLyricsLayout` 头部调用）
- 翻译行显示：`LyricsComponents.kt` → `LyricLineItem` 底部 `AnimatedVisibility` + `showLyricsTranslation`/`translationFontSize`
- 平板右栏/手机歌词页调用入口：`TabletLyricsLayout.kt`(353 附近) / `PhoneLyricsLayout.kt`(312 附近) → `LyricsPanel`

## B. 设置（SharedPreferences `lyrics_settings`）

- 读取 API：`LyricsUtils.kt` → `rememberFloatPreference` / `rememberBooleanPreference`
- 默认值声明处（★要改默认值改这里，注意 Phone 与 Tablet 是两份）：
  - `PhoneLyricsLayout.kt`(97–116)、`TabletLyricsLayout.kt`(54–98)
- 导出 / 登记表：`LyricsUtils.kt` → `exportLyricsSettings`、`tabletLyricsSettingGroups`
- 设置 UI 分组与文案：`LyricsControlWidgets.kt` → `LyricsSettingsBottomSheet` + `SliderSettingItem` 等
- 常用键名与当前默认值：
  - 翻译字号 `translationFontSize = 20f`（默认 20sp）
  - 显示翻译 `showLyricsTranslation = true`
  - 边缘发光开关 `enableEdgeGlow = false`（默认关闭）
  - 边缘发光参数 `rightEdgeGlowRadius=98` / `beatGlowThreshold=0.1` / `beatGlowDelayMs=352.9`
  - 封面光晕 `glowBrightness=0.09` / `glowBreathFrequency=0.5` / `glowScaleSize=1.3`
  - 逐字 `enableWordByWord=true` / `yrcFloatSpeed` / `yrcFloatIntensity` / `wordScaleSpeed` / `wordScaleSize`
  - 行高/字号 `lineSpacingRatio` / `baseFontSizeRatio` / `activeLyricSizeRatio` / `verticalScrollSpeed` / `scaleAnimationSpeed`
  - 平板布局校准：`headerOffset*`/`coverOffset*`/`lyricsPanelOffset*`/`progressBar*`/`playback*`/`bottom*` 等（见 TabletLyricsLayout）

## C. 边缘发光 / 流光背景 / 封面光晕

- 边缘发光绘制与开关判定：`TabletLyricsLayout.kt`(155 附近) & `PhoneLyricsLayout.kt`(192 附近)，配合 `LyricsAnimations.kt` → `glowEffect`
- 低音采样来源：`player/SuiXinChangAudioProcessor.kt` → `currentAmplitude`
- 流光背景：`FlowingLightBackground.kt` → `FlowingLightBackground`（在 `LyricsScreen.kt` 全屏挂载）
- 封面主色提取：`LyricsUtils.kt` → `extractVibrantColor`
- 封面发光层绘制：`PhoneLyricsLayout.kt` → `PhoneAlbumPage`、`TabletLyricsLayout.kt`(254 附近)

## D. 播放控制 / 列表

- 进度条：`LyricsPlaybackComponents.kt` → `CustomProgressBar` / `ProgressBarOnly`
- 播放/模式按钮、全透明悬浮播放列表面板：`LyricsPlaybackComponents.kt` → `PlaybackControls`/`PlaylistOverlayPanel`(循环模式在播放列表内切换)
- 播放列表「跟手拖拽+松手吸附」开合：`TabletLyricsLayout.kt`(左栏封面内容上滑)/`PhoneLyricsLayout.kt`(封面页上滑) → 各布局内 `openPx`(0..左栏高)/`maxOpenPx`/`settle()`/`snapClosed()`；封面/控件整体 `translationY=-openPx` 上移、列表 `translationY=maxOpenPx-openPx` 从底部露出。关闭=播放列表顶部整块区域下拖跟手，或歌单滚到顶再下拉(嵌套滚动 `PlaylistOverlayPanel` 内 `closeNested`)；歌词列不受影响
- 设置按钮：手机/平板标题行右侧 `Tune` 图标 → `showSettings`(设置弹层 `LyricsControlWidgets.kt`)
- 迷你播放条：`PlayerBar.kt`
- 随心唱按钮与弹层：`LyricsControlWidgets.kt` → `SuiXinChangButton`；状态/请求在 `LyricsViewModel.kt` + `SuiXinChangApi.kt`

## E. 播放 / 网络 / 加密（改后台逻辑）

- 播放器状态与队列：`MusicPlayer.kt`（`playerState`）
- 网易云接口/加密：`NeteaseApiService.kt`、`ApiClient.kt`、`NeteaseCrypto.kt`
- 歌词解析与行定位：`LyricsViewModel.kt`（`parseLrc`/`parseYrc`/`updateCurrentLine`）、模型 `Models.kt`
